# Verdi.Code — Día 1

Primera versión del portafolio personal de Agustín.

## Qué incluye

- Estructura HTML semántica.
- Navegación por secciones.
- Presentación, información personal y habilidades.
- Servicios, proyectos, proceso y contacto.
- Una base pequeña de CSS para ordenar y leer el contenido.
- Adaptación básica para celular.

## Qué todavía no incluye

- JavaScript.
- Menú móvil desplegable.
- Calculadora funcional.
- Animaciones.
- Imágenes de proyectos.
- Logo gráfico.
- Personaje 3D.

## Archivos

- `index.html`
- `css/styles.css`
